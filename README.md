# 📚 AI Revision Studio

An AI-powered revision companion that transforms raw lecture notes and PDFs into interactive flashcard decks, self-assessment quizzes, and downloadable study guides.

## ✨ Features
- **Smart Note Processing:** Accepts raw text or uploaded lecture PDFs.
- **Structured AI Extraction:** Powered by Google Gemini 2.5 Flash using structured Pydantic schemas.
- **Interactive Flashcards:** Clean flip-card mechanics with Next/Previous navigation and inline editing.
- **Auto-Graded Quizzes:** Multiple-choice quizzes with instant feedback and explanations.
- **Session History & Auth:** Multi-user isolation with persistent history tracking.
- **Export Options:** Download as Printable Study Guide (HTML/PDF), Anki CSV, or raw JSON.
